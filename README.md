# 스마트폰 카메라 기반 물리 실험 데이터 자동 분석 툴

스마트폰으로 찍은 공 낙하·포물선 운동 영상을 분석해서, 프레임별 위치·속도·가속도와 중력가속도 g를 자동으로 계산합니다.

## 주제

- 물리 원리: 2차원 평면 운동학(등가속도 운동), 에너지 보존
- 알고리즘: HSV 색상 마스킹과 윤곽선 검출로 공 추적, 기준 자를 이용한 픽셀→미터 보정, 2차 곡선 맞춤(최소제곱법), 국소 2차 회귀(Savitzky–Golay 방식)로 노이즈를 줄인 속도·가속도 계산
- 개발 방식: 바이브 코딩

## 진행 상황 (3일차, 완성)

- [x] 1일차: HSV 색상 추적, 프레임별 픽셀 좌표 CSV, 테스트 영상 생성기
- [x] 2일차: 픽셀→미터 보정, 2차 곡선 맞춤으로 g 추정(표준오차·95% 구간), 국소 2차 회귀로 속도·가속도, 그래프·요약
- [x] 3일차: 클릭으로 설정(`--pick`, calib.json), 분석 구간 자동 선택, 역학적 에너지 분석, 궤적 영상 저장

개발 과정은 [DEVLOG.md](DEVLOG.md)에 정리했습니다.

## 설치

Python 3.9 이상이 필요합니다.

```
pip install -r requirements.txt
```

## 빠르게 해 보기 (테스트 영상)

실제 영상을 찍기 전에, 물리 법칙대로 떨어지는 공 영상을 만들어서 툴을 시험해 볼 수 있습니다.

```
python make_test_video.py
python ball_tracker.py test_drop.mp4 --color orange --scale-points 40,70,40,370 --scale-length 1.0 --save-video
```

`test_drop_result/` 폴더에 결과가 저장됩니다. g = 9.807 m/s²로 만든 영상에서 9.810 ± 0.004 m/s²가 나옵니다.

## 실제 영상 분석

### 촬영 방법

- 폰을 삼각대나 책 위에 고정하고, 공이 움직이는 면과 수직이 되게 옆에서 찍습니다.
- 공은 배경과 색이 확실히 다른 것(주황색 탁구공 등)이 좋습니다.
- 공이 떨어지는 면과 같은 거리에 자나 길이를 아는 물체를 같이 찍습니다. 거리가 다르면 원근 때문에 길이가 틀어집니다.
- 슬로모션(120~240 fps)으로 찍으면 점이 많아져서 결과가 정확해집니다.

### 실행

처음에는 `--pick`으로 실행해서, 화면에 뜬 첫 프레임에서 ① 공 ② 자의 한쪽 끝 ③ 자의 다른 쪽 끝을 차례로 클릭하고, 자의 실제 길이(m)를 입력합니다. 설정은 `calib.json`에 저장됩니다.

```
python ball_tracker.py my_drop.mp4 --pick
python ball_tracker.py my_drop2.mp4 --calib calib.json     # 같은 촬영 조건이면 설정 재사용
```

**슬로모션 영상은 실제 촬영 fps를 꼭 지정하세요.** 폰은 240 fps로 찍어도 파일에는 30 fps로 저장하는 경우가 많아서, 그대로 분석하면 g가 64배 작게 나옵니다.

```
python ball_tracker.py slowmo.mp4 --calib calib.json --fps 240
```

### 주요 옵션

| 옵션 | 설명 |
|---|---|
| `--pick` | 화면 클릭으로 공 색상과 기준 길이 설정 |
| `--color orange` | 색상 프리셋 (orange, yellow, green, blue, red, pink) |
| `--scale-points x1,y1,x2,y2` + `--scale-length L` | 기준 물체 양 끝 픽셀 좌표와 실제 길이(m) |
| `--fps 240` | 실제 촬영 fps |
| `--start 1.2 --end 2.0` | 영상의 일부 구간(초)만 분석 |
| `--no-auto` | 놓기 전 정지 구간과 바닥에 닿은 뒤 구간을 자동으로 빼지 않음 |
| `--smooth 7` | 속도 계산 창 크기 (가속도는 2배+1) |
| `--save-video` | 궤적을 그린 영상도 저장 |

## 결과물

| 파일 | 내용 |
|---|---|
| `track.csv` | 프레임별 픽셀 좌표, 시간, 위치(m), 맞춤값, 속도, 가속도, 역학적 에너지 |
| `analysis.png` | 위치·속도·가속도·역학적 에너지 그래프 4개 |

## 계산 방법

1. **공 추적**: 프레임을 HSV 색공간으로 바꿔 공 색 범위만 남기고(마스킹), 열림·닫힘 연산으로 잡티를 지운 뒤, 윤곽선 중 면적이 충분하고 원형도(4π·면적/둘레²)가 높은 것을 공으로 고릅니다. 후보가 여러 개면 직전 프레임 위치와 가까운 것을 우선합니다.
2. **보정**: 기준 자 양 끝의 픽셀 거리 ÷ 실제 길이 = px/m. 화면 좌표는 아래쪽이 +라서 위쪽이 +가 되도록 부호를 바꿉니다.
3. **구간 선택**: 가장 길게 연속으로 추적된 구간에서, 공이 움직이기 시작한 프레임부터 바닥에 닿기 직전 프레임까지만 씁니다.
4. **g 추정**: y(t) = c₂t² + c₁t + c₀를 최소제곱법으로 맞추면 가속도는 2c₂이므로 g = −2c₂. 맞춤의 공분산 행렬로 표준오차와 95% 구간을 계산하고, 이론값(9.80665 m/s²)이 구간 안에 있는지 확인합니다.
5. **속도·가속도**: 각 점 주변 몇 개 점에 2차식을 맞춰 그 점의 기울기(속도)와 곡률(가속도)을 구합니다. 단순 차분보다 노이즈에 강합니다.
6. **에너지 보존**: 단위 질량당 역학적 에너지 ½v² + g·y가 시간에 따라 얼마나 변하는지 보고, 공기 저항이나 측정 오차를 가늠합니다.

## 오차 요인

- 원근: 자와 공이 카메라에서 다른 거리에 있으면 길이 보정이 틀어집니다.
- 렌즈 왜곡: 화면 가장자리일수록 직선이 휘어 보입니다. 공이 화면 가운데쪽에서 움직이게 찍으세요.
- 움직임 번짐: 공이 빠르면 길쭉하게 번집니다. 밝은 곳에서 셔터가 빨라지게 찍으세요.
- 공기 저항: 가벼운 공(탁구공)은 낙하 거리가 길수록 g가 작게 나옵니다.
